# Relevance of texture and intensity information

A neural network classifies 9×9 patches of the VessMAP dataset as vessel or background, while texture and intensity information is selectively removed from the patches. Since the patches are small, the network has almost no access to the shape of the vessels, so the experiment measures how much intensity and texture alone contribute to recognizing vessels.

| Dataset | Perturbation | `--perturbation` |
|---|---|---|
| $D$ | none | `none` |
| $D_{-i}$ | intensity normalization (zero mean, unit std) | `i` |
| $D_{-t}$ | pixel shuffling | `t` |
| $D_{-i,-t}$ | normalization and shuffling | `it` |

Vessel patches contain a fraction $f$ of vessel pixels (`--fraction 1.0`, `0.75` or `0.5`). With $f=100\%$ there are no border cues. Background patches contain only background pixels.

## Running

Place the VessMAP dataset in `data/VessMAP` (see the main README) and run, inside this directory:

```bash
# 1. Extract the patches (539 vessel patches for f=100%, 700 for f=75% and 50%, 700 background patches)
python extract_patches.py --fraction 1.0
python extract_patches.py --fraction 0.75
python extract_patches.py --fraction 0.5

# 2. Train all configurations of the paper: 4 perturbations x 3 fractions x 5 seeds (1, 2, 10, 1998, 2907)
python train_classification.py --all

# 3. Mean accuracy, 95% confidence interval and one-tailed t-test against D
python summarize.py
```

A single configuration can be trained with, e.g., `python train_classification.py --fraction 1.0 --perturbation it --seed 1`.

Each run trains for 300 epochs with Adam (learning rate 0.001), batch size 9 and the cross-entropy loss, using a random 80/20 train/test split defined by the seed. The reported accuracy is the test accuracy at the epoch with the smallest test loss.

## Outputs

All paths are relative to the `classification` directory and can be changed with the `--output_dir` (`extract_patches.py`, `train_classification.py`), `--patches_dir` (`train_classification.py`), `--results_dir` and `--output` (`summarize.py`) options.

| File | Created by | Content |
|---|---|---|
| `patches/vessel_f100.npz`, `patches/vessel_f75.npz`, `patches/vessel_f50.npz` | `extract_patches.py` | Vessel patches for each fraction $f$: array `patches` (N×9×9, original intensities) and the name of the source image of each patch (`names`) |
| `patches/background.npz` | `extract_patches.py` | Background patches, in the same format |
| `results/{perturbation}_f{100,75,50}_seed{seed}.json` | `train_classification.py` | Test accuracy and loss at the best epoch, the best epoch and the train/test accuracy and loss of all epochs up to it |
| `results/{perturbation}_f{100,75,50}_seed{seed}.pt` | `train_classification.py --save_model` | Weights of the model at the best epoch |
| `results/accuracy_summary.csv` | `summarize.py` | Mean accuracy, 95% confidence interval and p-value against $D$ for each fraction and perturbation |

The perturbation names in the files are `none` ($D$), `i` ($D_{-i}$), `t` ($D_{-t}$) and `it` ($D_{-i,-t}$).

## Files

- `extract_patches.py`: selection of patch centers through a convolution of the label with a 9×9 filter of ones.
- `perturbations.py`: normalization and pixel shuffling.
- `model.py`: network with two residual blocks of 64 channels.
- `train_classification.py`: train/test split and training.
- `summarize.py`: summary of the results over the seeds.

## Notes on reproducibility

- The patches generated by `extract_patches.py` are identical to the ones used in the paper.
- `summarize.py --legacy` reads the checkpoints saved by the original code of the dissertation (files named `T_e_I_mantida p100 seed_1.pickle`, etc., where `T_e_I_mantida`=$D$, `T_mantida`=$D_{-i}$, `I_mantida`=$D_{-t}$, `T_e_I_perdidas`=$D_{-i,-t}$). On those checkpoints it gives the accuracies reported in the paper: 85.37% ($D$), 81.57% ($D_{-i}$), 85.28% ($D_{-t}$) and 78.24% ($D_{-i,-t}$) for $f=100\%$.
- The original code did not seed the network initialization. `train_classification.py` sets `torch.manual_seed(seed)`, so new runs are repeatable but will not reproduce the original numbers exactly.
- The candidate centers use `int(81*f)` vessel pixels (81, 60 and 40 for $f$ = 100%, 75% and 50%).
- `shuffle_pixels` reseeds the random generator on every call, so the same permutation is applied to all patches of a run. This is the behavior of the code that generated the results of the paper.
